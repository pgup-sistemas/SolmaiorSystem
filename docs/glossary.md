# 📖 Glossário de Termos

| Termo | Definição |
|-------|-----------|
| **Aula Regular** | Aula recorrente dentro da grade do aluno, geralmente semanal. |
| **Aula Experimental (Trial Lesson)** | Primeira aula gratuita ou introdutória para avaliar interesse do aluno. |
| **Reposição** | Aula agendada para compensar uma ausência justificada do aluno. |
| **Mensalidade** | Valor recorrente pago pelo aluno ou responsável referente ao plano contratado. |
| **Recital** | Evento público organizado pela escola para apresentações dos alunos. |
| **Performance** | Apresentação individual ou em grupo avaliada por professores. |
| **Lead** | Interessado capturado pela landing page ou pela secretaria (potencial aluno). |
| **Matrícula** | Formalização da entrada do aluno no sistema com contrato ativo. |
| **Plano** | Combinação de carga horária, instrumento e valor associado ao aluno. |
| **Role (Perfil)** | Conjunto de permissões atribuídas a um usuário dentro do sistema (ex.: aluno, professor, secretaria, admin). |
| **Schedule (Agenda)** | Reserva de horário de aulas e eventos, incluindo sala, professor e alunos. |
| **Turma** | Grupo de alunos associados a um professor e instrumento. |
| **Inadimplência** | Situação em que o aluno possui pagamentos vencidos sem quitação. |
| **Dashboard** | Tela com indicadores e métricas para tomada de decisão. |
| **CTA (Call to Action)** | Botão ou link na landing page usado para incentivar ações (ex.: solicitar aula experimental). |
| **Workflow** | Sequência de etapas automatizadas (ex.: agendar aula experimental → enviar email → aguardar confirmação). |
| **KPI (Key Performance Indicator)** | Indicador-chave de desempenho, como taxa de conversão ou ocupação. |
| **Auditoria** | Registro detalhado de ações críticas (financeiro, exclusões, alterações de permissões). |
| **Token de Confirmação** | Código único enviado por email para confirmar presença em aula experimental. |
| **Lembrete Automático** | Mensagem enviada pelo sistema antes de uma aula ou evento, por email ou SMS. |
| **Fila de Tarefas** | Mecanismo assíncrono (ex.: Celery/Redis) para executar envios de email e notificações. |

> **Atualize este glossário** sempre que um novo termo ou sigla for adotado pela escola. Registre a alteração em [`updates.md`](updates.md).
