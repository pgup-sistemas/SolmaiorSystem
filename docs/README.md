## 📦 Requisitos para publicação

- Todo conteúdo está em Markdown (`.md`).
- As pastas formam uma arquitetura compatível com plataformas como GitHub Pages, Notion, Confluence ou ReadTheDocs.
- Todas as seções possuem títulos, subtítulos e áreas reservadas para imagens ou anexos.

## 🗂 Convenções adotadas

- **Capturas de tela** devem ser adicionadas substituindo o texto `![Placeholder](../static/screenshots/placeholder.png)` pelo caminho real da imagem.
- **URLs** internas utilizam caminhos relativos para funcionar em qualquer plataforma.
- **Chamadas de atenção** utilizam sintaxe Markdown padrão com blocos `>`, tabelas e listas.
